# Avatar assets

The production avatar system is generated from SVG primitives and TypeScript in `packages/avatar`; it does not depend on raster portraits or downloaded avatar packs.

- `references/` documents outside visual references and their provenance.
- `source/` is reserved for editable artwork created for Stave.
- `exports/` holds generated previews for design review and is ignored by default.

Do not copy third-party character artwork into production assets without confirming its license.
