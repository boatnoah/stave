# Stave feature map

This map covers the current product workspace and the avatar lab available from Settings.

| Feature | Proof target |
| --- | --- |
| [Workspace setup and board](workspace-board.md) | Create a local project and ticket, inspect board stages and saved ticket details. |
| [Run lifecycle and decisions](run-lifecycle.md) | Cancel and complete simulation work; answer a Codex decision and resume its turn. |
| [Team chat](team-chat.md) | Send a team message, create a ticket from chat, and reply in its thread. |
| [Git workspaces](git-workspaces.md) | Prepare and refresh a ticket worktree while preserving its branch and unfinished file. |
| [Workspace persistence](workspace-persistence.md) | Reopen the saved project, tickets, and run history in a fresh app instance. |
| [Delayed boot screen](boot-screen.md) | Show the stacked S only when opening the workspace takes longer than 300 ms. |
| [Avatar state preview](state-preview.md) | Selecting a state updates every displayed agent and its accessible state. |
| [Living crew](living-crew.md) | Each lab agent has a visible identity, role, activity, and accessible avatar. |
| [Board-size task cards](board-cards.md) | Compact study cards retain ticket, priority, owner, avatar, and state information. |
